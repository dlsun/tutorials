# Outputs on the synthetic data

These are the files `Code/run_pipeline.sh` writes when it is run on the
synthetic data in `Data/`. They are here so that a run can be checked against
them. They say nothing about the real experiment, whose results are in the
paper. `Code/PIPELINE.md` ("Outputs of a run") describes each file. The logs
(`*.log`) are written too but are not committed.
